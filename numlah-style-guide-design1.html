Red is reserved for two uses only: destructive actions (clear/delete) and negative Reality Check net figures. Never used for CTAs.
Gold is reserved for starring (active star fill #B8871E), and now also the unread-notification accent (badge dot, unread card left-border + tint) — same colour, same "something needs attention" meaning.
Charcoal gradient is used for all primary CTAs, active toggle/pill states, and the Shake Me Lah edge ribbon.
Mono-blue (#173A63) is reserved exclusively for ALL-CAPS mono eyebrow labels (LAST SEEN, PRIZE, GAP STAT, WHAT STANDS OUT, etc.) and the info-tooltip "i" icon — never applied to data values, which stay in Muted grey. This keeps "label" and "value" visually distinct at a glance.

08

Copy Voice — Singlish

Principles
Sarah Lim's voice is playful, warm, and conversational — like a friend teasing you about your lucky numbers, never a hype machine. Singlish appears in insights and empty states — the places people actually linger — never in the ~3s processing overlay, which is plain English only.
lah — declarative, familiar. "Every number confirm got history lah."
leh — soft, slightly resigned. "This one very shy leh — no recorded appearance."
sia — mild surprise/emphasis. "Wah, long time no see this number sia."
wah — exclamation. "Wah, long time no see…"
confirm — absolute certainty. "Position confirm MIA the longest."
kaypoh — nosy/always-around. "…is the kaypoh one, always showing up."
blur — clueless/empty. "Favourites section still blur blur empty leh."

10

Feedback & Guardrails

Unread Notification Badge
Trigger: any notification with unread state present
Hamburger icon: 12px gold dot, top-right corner, 2px background-colour ring for contrast against the icon's lines
Menu drawer row: 10px gold dot inline after the "Notifications" label, before the chevron
Mark-as-read: triggers when the user navigates away from the Notifications screen (back button or closing the whole menu) — not the instant it opens, so the unread state stays visible while actually reading
Unread vs Read Notification Card
Unread: warm gold-tinted background (#FEFAF1) · 3px gold left border · bold title (700) · small gold dot before title text
Read: plain white card · no left accent · regular-weight title (500) in Muted grey — recedes so unread items pop by contrast
Rationale: three simultaneous signals (colour + weight + accent) rather than one, so it reads clearly even at a glance
TOTO Selection Cap Feedback
Behaviour: tapping an 8th number once 7 are already picked shows a brief inline hint ("Max 7 numbers — remove one to pick another.") in red beneath the grid, auto-hiding after ~1.8s
Why: previously this tap did nothing with zero feedback — a user could reasonably think the app had glitched rather than realise they'd hit the cap
11

Localisation — Theme & Language

Preferences Rockers
Theme rocker: Chit Chat / Teh Tarik — reuses the same .toggle-track/.toggle-btn component as the 4D/TOTO selector, so it's visually native rather than a new pattern
Language rocker: English / 中文 — same component, sits directly below Theme
Engine: a STRINGS object with parallel en/zh keys + a t(key) lookup function. Every screen — setup, results, Reality Check, menu, notifications, history, favourites, about — re-renders fully in the selected language via the existing render() dispatcher; no separate DOM-patching layer needed since D1 already regenerates screens from state.
Tooltips: a parallel tooltipText(key) helper keeps the info-tip popovers bilingual too.
Translation Register
Mandarin copy mirrors the Singlish voice's warmth rather than translating literally — informal, spoken-register phrasing a Chinese-educated Singaporean would actually use.
"Wah, long time no see this number sia" → 哇，这个号码好久没出现了咧
"…is the kaypoh one, always showing up" → 是最常出现的常客
"Sure you want to remove this number ah?" → 确定要删除这个号码吗？
Processing overlay stays plain in both languages — same reasoning as Section 08: on screen too briefly for voice to land.
